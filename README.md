# OpenBooks — نظام محاسبة أونلاين للموبايل

نسخة محاسبية مستقلة مستوحاة من فكرة Manager.io — مبنية من الصفر (مش تفكيك للكود الأصلي)، وتعمل كتطبيق ويب تقدّمي (PWA) على الموبايل.

## المزايا (MVP)

- **محاسبة القيد المزدوج** — كل مستند يتحول لقيد متوازن تلقائياً
- **دليل حسابات** جاهز (أصول/التزامات/ملكية/إيرادات/مصروفات) قابل للتوسيع
- **عملاء وموردون** مع كشف حساب ورصيد لحظي
- **فواتير بيع وشراء** ببنود متعددة وضريبة قيمة مضافة
- **مدفوعات** (تحصيل/دفع) مع توزيع تلقائي على أقدم الفواتير
- **قيود يدوية** مع التحقق من توازن المدين والدائن
- **تقارير**: قائمة الدخل، الميزانية العمومية، ميزان المراجعة، أعمار الديون، دفتر اليومية
- **PWA**: يُثبَّت على الموبايل، واجهة عربية RTL، يعمل بدون إنترنت للواجهة

## التشغيل

```bash
pip install fastapi "uvicorn[standard]" sqlalchemy pydantic python-multipart
python -m uvicorn app.main:app --host 0.0.0.0 --port 12000
```

افتح: `http://localhost:12000` — الدخول الافتراضي: **admin / admin123**

## إعادة تعيين البيانات

```bash
python -m app.reset          # بيانات نظيفة (دليل حسابات + مستخدم)
python -m app.reset --demo   # + بيانات تجريبية
```

## البنية

```
app/
  database.py    اتصال قاعدة البيانات (SQLite افتراضياً، أو PostgreSQL عبر DATABASE_URL)
  models.py      الجداول: حسابات، جهات، فواتير، مدفوعات، قيود
  accounting.py  محرك القيد المزدوج والتقارير المالية
  security.py    تشفير كلمات المرور (PBKDF2) والرموز الموقّعة
  seed.py        دليل الحسابات القياسي
  routers/       نقاط الـ API
static/          واجهة الموبايل (HTML/CSS/JS بدون build)
```

## ملاحظات

- البيانات المالية **لا تُخزَّن كأرصدة**، بل تُحسب من القيود — فلا يمكن أن تتعارض التقارير مع الدفاتر.
- للاستخدام في الإنتاج: غيّر `APP_SECRET`، استخدم PostgreSQL عبر `DATABASE_URL`، وفعّل HTTPS.
